# docx-template

Сервис шаблонизации на основе docx-файлов 

Сервис умеет:
  * создавать и хранить шаблоны на основе docx-файлов
  * генерировать pdf по шаблонам, подставляя переданные данные в размеченные в шаблоне теги (Например, тег {{ДатаДокумента}}) 
 
Для генерации документов по шаблонам используется библиотека [poi-tl](https://github.com/Sayi/poi-tl).

### Хранение 
1. Для хранения используется postgres
2. Данные о шаблонах хранятся в таблице templates
3. Файлы шаблонов хранятся в отдельной таблице files_

### Конфиг приложения `application.yaml`

```yaml

logging:
  level:
    org.apache.fop: ERROR
    org.docx4j: ERROR
    ROOT: INFO

server:
  port: 8099

spring:
  application:
    name: docx-template
  datasource:
    jdbc-url: jdbc:postgresql://docx_template_db:5432/docx_template
    username: docx_template
    password: docx_template
```


### API

[OpenAPI](./docs/openapi.yaml)

1. Создание шаблона

_POST api/templates_

При создании автоматически определяется версия шаблона. Если нет шаблонов с таким именем, то будет первая версия, иначе "последняя версия + 1".
Если файл не передан, то используется файл-заглушка - файл в котором просто перечислены теги

2. Генерация pdf по шаблону последней версии

_POST api/templates/{templateName}/pdf_

Возвращается 404, если нет шаблона с таким именем.
Если в request body нет данных, то в шаблоне ничего не будет заменено

3. Генерация pdf по шаблону определенной версии

_POST api/templates/{templateName}/{templateVersion}/pdf_

Возвращается 404, если нет шаблона с таким именем или такой версии.
Если в request body нет данных, то в шаблоне ничего не будет заменено

4. Поиск шаблонов

_GET api/templates_

Возвращает список данных о шаблонах или пустой список, если ничего не найдено

5. Скачивание шаблона

_GET api/templates/{templateName}/{templateVersion}/file_

Возвращает docx-файл (шаблон). Возвращает 404, если нет шаблона с таким именем или такой версии

6. Получение информации по шаблону

_GET api/templates/{templateName}_

Возвращает информацию о шаблоне. Возвращается 404, если нет шаблона с таким именем

7. Получение информации по шаблону и версии

_GET api/templates/{templateName}/{templateVersion}_

Возвращает информацию о шаблоне. Возвращает 404, если нет шаблона с таким именем или такой версии

## Проверка здоровья сервиса и готовность принять запросы

### Readyness проба

Readyness проба тестирует готовность приложения принять запросы (прошли все миграции, правильно сконфигурирован доступ к БД)

`/system/health/ready` - в случае успеха отдает код ответа 200

### Livness проба

Livness проба НЕ включает тестирование доступа к БД, иначе при проблемах с БД приложение перезапускается бессмысленно.
Livness проба включает тестирование внутреннего соcтояния сервиса (например, зависшие джобы), которое можно восcтановить перезапуском приложения.

`/system/health/live` - в случае успеха отдает код ответа 200

### Локальный запуск сервиса

В терминале из директории проекта выполнить команду для поднятия внешних зависимостей сервиса
```shell
docker-compose up -d
```

В IDE выполнить запуск проекта с Spring профилем **dev** или выполнить команду в терминале директории проекта
```shell
mvn spring-boot:start -Dspring-boot.run.profiles=dev
```

Используются версии: Java 17, PostgreSQL 13
